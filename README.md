# Свадбена покана — Мирослав & Марија (нов дизајн)

Оваа верзија е со:

- нов различен дизајн
- песна: `background-song.mp3`

За GitHub Pages:
1. Upload-ирај ги сите фајлови од овој folder во repository.
2. Осигурај се `index.html` да е во root.
3. Settings → Pages → Deploy from branch → `main` / `(root)`.
